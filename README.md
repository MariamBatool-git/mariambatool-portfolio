## 🧰 Running Locally

```bash
git clone https://github.com/MariamBatool-git/mariambatool-portfolio.git
cd mariambatool-portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it in the browser.
